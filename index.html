Is a lactate of 319.8 mg/dL real?
A 76-year-old man with HCC and refractory shock

Case recap 病例摘要、關鍵時間軸與原始問題

一位 HBV 相關肝硬化 Child C、反覆復發 HCC 的 76 歲男性，因腹脹與下肢水腫入院，住院第 26 天進入難治性休克，臨終前中央實驗室乳酸達 319.8 mg/dL（35.5 mmol/L）。

  1. 08/16 — D0急診：腹脹、雙下肢水腫 2 週Na 118→117 mEq/L、CRP 121.48 mg/L、WBC 16.8 K（seg 85%）、T-bil 7.8 mg/dL、lactate 12.1 mg/dL（正常）
  2. 08/17腹部超音波HCC S5/8 7.37 cm、S7 8.99 cm；疑 CHD/CBD invasion；右側門靜脈廣泛栓塞；中量腹水
  3. 08/20Pigtail 腹水引流WBC 52/µL、TP 0.7 g/dL、Rivalta negative、培養陰性（不支持 SBP）
  4. 08/27上消化道出血Coffee-ground ~100 g、SBP 79 mmHg；家屬拒絕插管與胃鏡
  5. 09/01 — D16肝昏迷 + AKI/HRS，轉 MICUNH₃ 212 µg/dL、BW 47.5→40.5 kg；terlipressin
  6. 09/08MRI：腫瘤 ~10 cm右側門靜脈與肝靜脈栓塞、icteric HCC、癌性腹膜炎、EV/GV
  7. 09/09 — D24嗆到後休克BP 62/37 mmHg；meropenem + teicoplanin；Levophed；pH 7.188、HCO₃⁻ 8.5、lactate 23.4 mg/dL
  8. 09/10大量出血、插管、CVVHNG 鮮血 800 mL + 血便 400 mL；ETT+MV；lactate 117.9 → 219.1 mg/dL
  9. 09/11 — D26DIC、臨終INR 3.5、D-dimer 27.46、FDP 38.5；AST 6290 / ALT 3014；lactate 319.8 mg/dL；13:37 死亡（DNR）
原始問題（來自 MICU 照會，原文保留）

「病史：Chronic alcoholism，近期疑似飲用假酒。臨床表現：生命徵象穩定，無休克徵象……Lactate 320 mg/dL（約 35.5 mmol/L），由中央實驗室 Beckman Coulter AU 測得。High anion gap metabolic acidosis（AG 41），Osmolal gap 39……院內 POCT 血氣機沒有開放 Lactate 項目。臨床疑問：病人無明顯休克，難以單用 Type A lactic acidosis 解釋高達 320 mg/dL 的乳酸；臨床醫師懷疑是否為假酒代謝物（Glycolate / Glyoxylate）造成儀器無法分辨而出現偽陽性。」

重要落差題目情境與病歷不符：病歷記載已戒酒 5 年、血壓 62/37、三種升壓劑、CVVH；AG 41／OG 39／NH₃ 1260／INR 9.0 亦與檢驗報告（AG 計算 51.5、未驗滲透壓、NH₃ 最高 332、INR 最高 3.5）不同。本站與簡報一律以病歷與檢驗報告為準，並在方法學討論時使用題目設定。

Method explorer 檢驗原理、方法差異與機台比較（可切換）

三種乳酸測定原理，決定「交叉反應」與「干擾方向」完全不同。以下數值與敘述均取自各原廠 IFU（2022–2024 年版）。

Beckman Coulter AU — LACT (OSR6193)

原理
LOD 氧化 L-lactate → pyruvate + H₂O₂；POD 催化 H₂O₂ + 4-aminoantipyrine + 氫供體（TOOS）→ 呈色 quinoneimine，光度終點法。
檢體
氟化鈉／草酸鉀血漿（不用血清）；抽血後 15 分鐘內離心、冰浴。IFU 明列：icteric 與 hemolyzed 檢體應避免。
線性範圍
0.22–13.32 mmol/L（2–120 mg/dL）→ 本案 145、219、232、319.8 皆超出上線，必須稀釋。
干擾（IFU 實測）
黃疸 <10% 或 0.25 mmol/L，最高測到 bilirubin 8 mg/dL；溶血 <5%（Hb ≤5 g/L）；ascorbate <10%（≤2 mg/dL）；lipemia <3%（≤1000 mg/dL）。
方向
NAC 治療與 metamizol（dipyrone）採血 → 假性偏低。IFU 未列 glycolate／glyoxylate。
校正
System Calibrator 66300，可追溯至 gravimetric 一級標準（reagent-grade L-lactate）；total CV 1.7–2.1%。

Roche cobas c — LACT2 (Lactate Gen.2)

原理
同為 LOD + POD 呈色法（4-AAP + 氫供體）。R1 內含 ascorbate oxidase（cucumber），用以削減維生素 C 干擾。
檢體
NaF/K-oxalate 或 NaF/Na-heparin 血漿；不用血清；15 分鐘內離心。
與 AU 的差異
同樣是 LOD 酵素法 → 跨平台一致無法排除 glycolate；ascorbate oxidase 使還原劑干擾的方向與幅度可能不同。

Abbott Alinity c — Lactic Acid2

原理
LOD → pyruvate + H₂O₂；POD 催化 H₂O₂ 與 TODB + 4-AAP 氧化偶聯，形成 quinoneimine 染料，604 nm 定量。
試劑
TODB 1.186 g/L；4-AAP 0.325 g/L；LOD 2.400 kU/L；POD 4.000 kU/L。
意義
色原與波長與 AU（TOOS/4-AAP）不同，但受質特異性仍取決於 LOD。

LDH UV 法 — 真正有鑑別力的「第二方法」

原理
L-lactate + NAD⁺ —LDH→ pyruvate + NADH，340 nm 吸光度上升；不使用 LOD，因此理論上不受 glycolate 干擾。
現況
目前主流生化平台少用；文獻（Tintu 2013）中只有 LDH 法不受 glycolate／glyoxylate 影響。
臨床用途
若院內可取得，LOD 與 LDH 法之間的差距（lactate gap）才是可解釋的證據；單靠三台 LOD 平台互比不足。

Glycolate / glyoxylate 為何會「變成乳酸」

機轉
glycolate 亦是 LOD 的受質：glycolate + O₂ → glyoxylate + H₂O₂。干擾發生在酵素層次，所以不分比色或電極法。
文獻
Tintu 2013（31 家醫院、20 種分析儀）：所有血氣機與多數 LOD 生化法假性升高，LDH 法不受影響；formate、oxalate、ethylene glycol 本身不干擾。Brindley 2007（CMAJ）：ABL700 嚴重高估，而 40 mmol/L glycolate 下 Beckman LX20 與 Vitros 僅升 ≤4 mmol/L。
甲醇呢
methanol 的代謝物是 formate，不是 LOD 受質 → 不干擾乳酸測定。這一點常被混淆。

已知事實

乳酸與 ΔAG 從 09/10 起幾乎平行上升；pH 在 09/10 中午後反而正常或偏鹼（BE 正值），同時 Na 由 138 升至 173。

Trinder 內源性干擾（黃疸、溶血、ascorbate、NAC）在 IFU 中皆為負向偏差。

合理推論

休克（失血性＋敗血性）＋ shock liver（AST 6290、AST>ALT）＋ Child C 肝硬化＋PV/HV 栓塞＋AKI，足以解釋 Type A 與 Type B 乳酸同時大量生成、且清除停擺。

AG 與乳酸吻合不能區分 L-lactate 與 glycolate：兩者在 AG 上的貢獻相同。

仍待確認

乳酸升高期間未驗血清滲透壓、ethanol、methanol、ethylene glycol、acetaminophen；無尿液草酸鈣結晶；09/10–11 無 LDH/CK；未做稀釋線性或第二方法確認。

09/09 total CO₂ 2.6 mEq/L 與同時間血氣 HCO₃⁻ 8.5 mmol/L 的落差未解釋（可能與採血管未滿或 CO₂ 逸散有關）。

Osmolal gap 的位置

唯一一次血清滲透壓為 08/17 13:23：259 mOsm/kg（同日 Na 121、glucose 97、BUN 18.3 → 計算約 254，OG ≈ 5）。

09/09–09/11 未驗 → 本案無法評估 osmolal gap；題目給的 OG 39 屬情境設定，不可當成病例事實。

結論（含確定程度）

本案最可能為真性 Type A + Type B 乳酸酸中毒（中度確定：時序、幅度與病程一致，且干擾方向不符）。若套用題目情境（無休克、酗酒、OG 39），則 glycolate 干擾必須積極排除，不能僅以「三台儀器結果一致」結案。

Take-home 四點帶走

  • Glycolate 是 LOD 的受質：干擾不限於血氣機，LOD 比色法也可能受影響；methanol 的 formate 則不干擾。
  • Trinder 的內源性干擾多為負向（黃疸、溶血、ascorbate、NAC）→ 無法製造假性升高；但本案 319.8 的黃疸程度已超出 IFU 測試範圍，屬「未涵蓋」而非「已排除」。
  • 三台 LOD 平台一致不代表沒有干擾；真正有鑑別力的是 LDH UV 法或 GC-MS，其次是稀釋線性與 reaction monitor。
  • AG 與乳酸吻合無法區分 lactate 與 glycolate；要區分必須靠 osmolal gap（先校正 ethanol）、尿液草酸鈣結晶或直接測定。
